# AI 중계 서버(AWS Lambda)

GitHub Pages 주소나 내려받은 html 파일에서 실시간 AI로 대화하려면 이 중계 서버가 필요하다. 화면이 만든 프롬프트(역할, 하네스, 교과서, 대화 기록)를 받아 Claude API에 넘기고 답을 돌려준다. API 키는 이 서버에만 두고 화면에는 넣지 않는다.

```
학생 화면(github.io) --프롬프트--> Lambda 함수 URL --API 키--> Claude API
                    <----답-----                  <---------
```

claude.ai 아티팩트에서는 이 서버를 쓰지 않고 내장 AI를 쓴다.

## 올리는 순서(AWS 콘솔, 약 10분)

1. Lambda > 함수 생성: 새로 작성, 런타임 Node.js 20.x 이상, 아키텍처는 아무거나.
2. 코드 탭에서 `index.mjs` 내용을 `lambda/index.mjs`로 바꾸고 Deploy.
3. 구성 > 일반 구성: 제한 시간 60초, 메모리 256MB.
4. 구성 > 환경 변수(아래 표).
5. 구성 > 함수 URL > 생성: 인증 유형 `NONE`. CORS는 끈다(코드가 직접 처리한다. 둘 다 켜면 헤더가 겹쳐 실패한다).
6. 만들어진 함수 URL을 화면의 연구자 보기 > 설정 > AI 서버에 넣고 '연결 시험'을 누른다.
7. 학생 기기 전체에 쓰려면 `source/src/data.js`의 `RELAY_DEFAULT`에 주소와 접속 코드를 넣고 빌드해 다시 올린다.

## 환경 변수

| 이름 | 필수 | 값 |
|---|---|---|
| ANTHROPIC_API_KEY | 예 | Anthropic 콘솔에서 만든 API 키 |
| ALLOWED_ORIGINS | 예 | `https://helloworld3414.github.io` . 내려받은 파일로 시험할 때만 `,null` 을 덧붙인다 |
| ACCESS_CODE | 아니요 | 화면의 접속 코드와 같은 값. 화면에서 보이므로 비밀이 아니다 |
| MODEL_QUICK | 아니요 | 화면 '빠름' 등급 모델. 기본 `claude-haiku-4-5-20251001` |
| MODEL_DEFAULT | 아니요 | 화면 '기본' 등급 모델. 기본 `claude-sonnet-5` |
| MAX_TOKENS | 아니요 | 답 길이 상한. 기본 600 |
| TEMPERATURE | 아니요 | 0~1. 두 조건에 같은 값이 쓰인다 |
| PER_SESSION_LIMIT | 아니요 | 가명 식별자 하나당 호출 상한. 기본 60 |
| LOG_TEXT | 아니요 | 1이면 프롬프트와 답 전문을 CloudWatch에 남긴다 |

모델 이름은 2026년 10월 기준 예시다. 투입 직전에 Anthropic 문서에서 현재 이름을 확인하고, 실험 기간 동안 바꾸지 않는다(확인 필요).

## 지키는 것과 남는 것

- 출처 제한: `ALLOWED_ORIGINS`에 없는 화면의 요청은 403으로 막는다.
- 횟수 제한: 가명 식별자마다 호출 수를 센다. 함수가 살아 있는 동안만 세는 간이 장치라, 실제 투입 때는 DynamoDB 같은 저장소로 옮기는 편이 맞다.
- 비용 상한: Anthropic 콘솔에서 월 사용 한도를 꼭 걸어 둔다. 키가 새도 피해가 한도 안에서 멈춘다.
- 기록: 호출마다 가명 식별자, 조건, 역할, 모델, 걸린 시간, 토큰 수를 CloudWatch에 JSON 한 줄로 남긴다. 대화 전문은 `LOG_TEXT=1`일 때만 남긴다.

## 연구 쪽 확인 사항

- 학생 대화가 외부 AI 회사로 넘어간다. IRB 계획서와 동의서에 넘어가는 곳, 보관 기간, 모델 학습 사용 여부를 적는다. 데이터 처리 조건과 미성년자 이용 조건은 Anthropic 정책 원문으로 확인한다(확인 필요).
- 화면이 보내는 것은 가명 식별자뿐이고 이름과 학번은 보내지 않는다. 학생이 대화에 적은 전화번호, 메일 같은 값은 화면에서 가린 뒤 보낸다.
- 두 조건은 같은 함수, 같은 모델, 같은 설정을 쓴다. 모델 이름이 응답마다 화면 기록(xAPI의 model 항목)에 남는다.

## 시험

키 없이 동작을 확인한다: `node server/lambda/test-local.mjs`
(정상 호출, 다른 출처 막기, 접속 코드, CORS 사전 요청, 횟수 제한, 등급별 모델, 파일로 연 화면)

## 다른 회사 모델로 바꾸려면

`index.mjs`에서 `fetch(API, ...)` 부분만 바꾸면 된다. 화면 쪽은 `{ text, model }` 형태의 JSON만 받으면 그대로 동작한다. 글자 단위로 흘려 보내는 응답(text/plain 스트림)도 화면이 받을 수 있다.
